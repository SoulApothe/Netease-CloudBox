# 云音盒子 · 使用文档

桌面版网易云音乐工具：**在软件内发现、试听、收藏，并把喜欢的歌带回家**。不需要命令行，不需要安装 ffmpeg。

> **版本提示**：当前源码与 `CloudBox.exe` 均为 **v3.5.0**（动态推荐 + 修复「换一批」不生效）。exe 为单文件免安装版，已实测可在无 Python 的电脑上直接打开原生窗口。

---

## 1. 第一次启动

**检查最新版（当前推荐）**：确认电脑装了 Python 3.10+ 并已加入 PATH，双击 **`启动桌面版.bat`**。首次会自动创建 `.venv` 并安装依赖，屏幕显示 `Installing dependencies (first run only)`，跑完后自动弹出「云音盒子」桌面窗口，关闭窗口即退出程序。之后启动是秒开。

**免 Python 方式**：双击 `CloudBox.exe`（约 21 MB 单文件）。不需要 Python、不需要装任何依赖。exe 所在文件夹就是程序根目录，Cookie、设置、收藏库和下载的歌曲都在这里。

**换电脑 / 发给别人**：不要连 `cookie.txt` 一起发。把 `CloudBox.exe` 单独发出去即可，对方首次双击会自动生成默认设置，`music` 文件夹建在 exe 同级，默认下载音质「极高 320 kbps」（不需要会员），需要登录时让对方自己扫码或粘贴自己的 Cookie。分发包可执行 `pack_dist.py` 生成，里面只有 `CloudBox.exe` + `cookie.example.txt`。

> 想回到纯 Web 服务：`python desktop.py --server --port 5000`，浏览器打开 `http://127.0.0.1:5000`。

## 2. 先弄清「三个身份」

软件里同时存在三种东西，它们互不打通，这是刻意设计的：

| | 用来做什么 | 存在哪 |
| --- | --- | --- |
| **网易云 Cookie** | **下载与在线播放共用**，解锁会员歌曲与无损 / Hi-Res 等会员音质 | `cookie.txt` |
| **软件账号** | 收藏歌曲、收藏歌手、创建自己的歌单（免注册免登录） | 本机 `cloudbox.db` |
| **匿名公开接口** | 歌曲推荐、站内搜索、歌单匹配 | 请求不落地；推荐权重只存本机 `settings.json` |

- 推荐来自**公开榜单 / 新歌 / 新碟**，请求时显式传入空 Cookie；「口味权重」只由本页播放 / 收藏 / 下载在本机计算，**不上传、不关联账号**。
- 在线播放会**优先使用 `cookie.txt` 的登录态**取直链（会员歌曲、无损 / Hi-Res 才拿得到），失败时退回匿名公开音质，所以没有 Cookie 也能听公开曲目。
- 软件账号没有注册和登录，收藏、歌手、歌单直接写本机 SQLite，**不联网、不上传、与网易云账号无关**。

**配置 Cookie（可选）**：`设置 → 下载凭证（网易云 Cookie）` → 扫码登录，或粘贴网页版 Cookie 后点「保存 Cookie」。没有 Cookie 也能下载标准 / 极高音质，但会员歌曲可能无法下载或播放；无损、Hi-Res、母带需要黑胶会员，SVIP 音质需要 SVIP。Cookie 同时服务于下载与在线播放。

**确认输出位置**：`设置 → 输出位置` 默认是根目录下的 **`music`** 文件夹。需要换位置就填完整路径或点「浏览」，填 `.` 可直接输出到根目录。

## 3. 界面导览

左侧导航分四组：

| 分组 | 页面 |
| --- | --- |
| 音乐 | **歌曲推荐**（主页）、搜索、我的音乐 |
| 下载工具 | 单曲解析、歌单下载、专辑下载 |
| 任务 | 下载队列（带未完成数量角标） |

- 顶部：全局搜索框（回车直达搜索）、主题切换、登录 / 账号入口、Cookie 状态胶囊。
- **底部播放器常驻**：显示封面、歌名、歌手、进度条（可拖动）、上一首 / 下一首、音量与播放队列。
- 最底部状态栏：输出目录、当前音质、版本号。
- 浅色 / 深色主题在 `设置 → 外观与关于` 切换，选择会自动记住。

## 4. 逛推荐与在线播放

第一次打开推荐页会弹一个小窗，让你勾选**喜欢的曲风**与**常听语言**（都可多选），点「保存并开始推荐」后，推荐歌曲会按这些关键词从公开曲库检索；不想选就点「先跳过」，推荐回退到公开榜单与新歌。随时可以在 `设置 → 在线播放` 或重开这个窗口修改（偏好只存在本机 `settings.json`，不读取 Cookie，也不建立账号画像）。

主页「歌曲推荐」有三个动作按钮：**播放推荐**、**换一批**、**下载目录**；下方还有站内搜索框，类型可切「歌曲 / 歌手 / 专辑 / 歌单」。

- 推荐区展示按偏好检索的歌曲、热门榜单卡片与新碟卡片。
- **换一批**：每次都会换一版内容 —— 热门歌曲在「热歌 / 飙升 / 原创 / 新歌」四张公开榜单间轮换并在榜内往后滑动，偏好检索会翻到下一页结果（60 首内循环），所以连续点会看到完全不同的歌。
- **动态推荐**：在本页**播放 / 收藏 / 下载**会累积「曲风 / 语言 / 歌手」权重（收藏权重最高，播放最低；20 秒内同一首歌只记一次），下一次「换一批」就按新权重排序并扩展检索。标题右侧会显示当前生效的权重，例如 `爵士 1.3 · 欧美 1.2`。
- 觉得推荐跑偏了：点推荐页说明区的 **重置动态权重**，或在偏好弹窗里重新保存一次选择（会同时清空歌手权重）。
- 权重只写在 `settings.json`，不上传，也不读取 `cookie.txt`；推荐请求依旧匿名。
- 歌曲行的 **▶** 播放、**♥** 收藏、**⬇** 直接下载；正在播放的那首会变成 **⏸**，再点一次就暂停，不会重新开始。
- 点榜单卡片可展开完整曲目；点专辑 / 新碟卡片可整张批量下载。
- 底部播放器支持上一首 / 下一首 / 拖动进度 / 音量；右侧 **⏱ 播放模式**按钮可在顺序播放 → 单曲循环 → 随机播放之间切换，也可在设置里选。
- **播放音质**与下载音质分开：`设置 → 在线播放 → 播放音质` 可选标准 / 极高 / 无损 / Hi-Res，取不到时自动往下降级；下载仍用「默认音质」。
- 在线播放由 `/api/stream` 代理，支持 `Range`，可任意拖动进度；解析直链时优先带 `cookie.txt` 的登录态，所以**会员歌曲也能直接播**，Cookie 无效或没配才退回匿名公开音质。
- 播放器歌名下方会显示当前实际档位：`会员 · 无损`、`会员 · Hi-Res` 表示用的是会员登录态；只显示 `极高` / `标准` 表示当前是匿名公开音质。鼠标悬停可看说明。
- 如果一首歌点播失败，提示会说明原因：Cookie 过期、会员专享、还是版权下架，而不是笼统的「无法播放」。
- **鼠标侧键**（后退 / 前进）可以直接在软件内翻页，等价于导航栏切换。
- 推荐不读取 `cookie.txt`，换一批靠榜单轮换与检索翻页，不会因网易云账号不同而变化。

## 5. 本机档案、收藏与我的歌单

**不需要注册、不需要登录**。软件第一次启动就会在根目录建好 `cloudbox.db`，收藏、歌手、本地收藏、自建歌单直接写进这个文件，删掉软件就等于删掉数据，不会上传到任何地方。

1. 推荐、榜单、搜索结果里的 **♥** 直接收藏歌曲，再点一次取消。
2. 搜「歌手」时，歌手卡片右上角的 **♥** 是**收藏歌手**，与歌曲收藏分开记录。
3. 「**本地音乐**」页里的 **♥** 收藏的是电脑上的音频文件（按文件路径记录），与在线歌曲分开。
4. 「**我的音乐**」页有四个标签：**在线收藏**、**收藏歌手**、**本地收藏**、**我的歌单**。
   - **我的歌单**：新建 / 删除歌单，往歌单里加歌、移除歌曲，整单播放或批量下载。
   - 在「添加到歌单」弹窗里点「新建歌单」，建完会**自动回到歌单选择列表**，顺手把刚才的歌存进去。
5. 右上角「本机档案」可看各类收藏数量；数据全在 `cloudbox.db`，想清空直接删除该文件。

> 网易云 Cookie 只用于下载解锁会员音质，和这里的收藏 / 歌单毫无关系。

## 6. 搜索与下载单曲

**搜索**：主页搜索框或「搜索」页，输入歌名 / 歌手 / 专辑名，或直接粘贴网易云链接，类型可切「歌曲 / 专辑 / 歌单」。搜「专辑 / 歌单」后点结果卡片会跳到对应的解析页。搜索结果的歌曲可直接播放、收藏或勾选批量下载。

**单曲解析**：左侧「单曲解析」→ 输入 ID 或链接 → 选音质 → 点「解析歌曲」，可看到封面、歌手、专辑、大小、时长、年份和歌词 → 点「**下载到 music**」，按钮下方会列出已写入的元数据标签。

**支持的输入**：纯 ID（`185668`）、歌曲 / 歌单 / 专辑链接、`#/` hash 路由链接、`163cn.tv` 短链、以及夹杂链接的分享文案。

---

## 7. 批量下载专辑 / 歌单

1. 左侧「专辑下载」或「歌单下载」→ 粘贴链接或 ID → 点「解析」。
2. 顶部信息卡显示封面、名称、歌手 / 创建者、曲目数、年份。
3. 点「**下载全部 N 首**」；或勾选部分曲目 → 「下载选中」。
4. 自动跳到「下载队列」，可看总进度、成功 / 跳过 / 失败数量、每首歌的进度条与失败原因，随时「取消任务」。
5. 完成后点「打开目录」或每行的「定位」找到文件。

**下载到哪个目录**：

- **整张专辑 / 整张歌单 / 榜单 / 歌手 / 收藏 / 导入歌单**：默认落到以内容名命名的子目录，例如 `music/范特西/`、`music/我喜欢的音乐/`。
- **单曲下载**（歌曲行 ⬇、播放器 ⬇、单曲解析页）：直接放 `music` 根目录，不建任何子文件夹。
- **搜索结果批量**：默认也落在 `music` 根目录（可用「按专辑分目录」开关控制）。
- 任一情况勾选「**合并到一个文件夹**」后，都会按任务标题建子目录，单曲也一样。

**合并到一个文件夹**：批量栏里有「**合并到一个文件夹**」勾选框。勾上后，这一批歌曲会一起放进以任务标题命名的子目录，例如 `music/周杰伦 · 范特西/`，适合整理整张专辑。想每次都这样，可在 `设置 → 下载偏好 → 批量合并到文件夹` 里打开全局开关；下载前的单次勾选会临时覆盖它。

批量栏右侧依次是音质下拉、**下载全部**（浅色，整张下）和**下载选中**（红色，只下勾选的）。工具条会紧贴在底部「本地服务运行中」状态条上方，列表滚到底也不会和最后一首歌拉开大段空白。

搜索结果的批量下载、榜单 / 新碟卡片、「我的歌单」整单下载同样适用这个开关。

批量任务会：一次性批量取详情与直链、按设置的并发数多线程下载、自动跳过已存在文件、逐首写入封面与元数据。专辑会自动写入曲目号、碟号与发行年份。

## 8. 文件命名

`设置 → 文件命名`，两种模式都带**实时预览**（下方三首示例曲目，改一下立刻变）。

### 简单模式（默认，推荐）

勾选要出现在文件名里的内容即可，不用记语法：

| 选项 | 效果示例 |
| --- | --- |
| 包含歌手 | `起风了 - 买辣椒也用券` |
| 包含专辑 | `起风了 (起风了)` |
| **包含专辑内顺序** | `01. 起风了` |
| 包含歌曲 ID | `起风了 [1330348068]` |
| 包含音质 | `起风了 [无损]` |

还能调「歌名与歌手顺序」「多位歌手全部保留 / 仅第一位」「连接符」。

**勾选「包含专辑内顺序」后**，下面会出现两个子选项（未勾选时灰化但始终可见，方便发现）：

- **序号与后面内容的连接符**：`. ` → `01. 歌曲名`、` - ` → `01 - 歌曲名`、`_` → `01_歌曲名`、空格 → `01 歌曲名`、`、` → `01、歌曲名`、方括号 → `[01] 歌曲名`。
- **序号位数**：1 位 `1.`、2 位 `01.`（推荐）、3 位 `001.`；不足补零，超过不截断。

例如选 ` - ` + 3 位，得到 `001 - 起风了.flac`。序号取自专辑 / 歌单的音轨号（接口没给音轨号时用列表顺序）；单独解析的一首歌若拿不到音轨号，则不会添加序号前缀。

### 模板模式（高度自定义）

点「模板模式」，用变量自由组合：

`{name}` 歌名 · `{artist}` 歌手 · `{album}` 专辑 · `{track}` 音轨号 · `{track:02d}` 补零音轨号 · `{year}` 年份 · `{id}` 歌曲 ID · `{quality}` 音质

示例：`{track:02d}. {name} - {artist} ({year})`。文件名里的非法字符会自动替换为下划线，多位歌手用「、」连接。

## 9. 写进歌曲里的信息

| 内容 | 说明 |
| --- | --- |
| 标题、歌手、专辑、专辑艺术家 | 多歌手分别写入，播放器可正确分组 |
| 专辑封面 | 内嵌为前置封面，不是外链；尺寸可在设置里调（默认 800px） |
| 音轨号 / 碟号 / 总曲目数 | 专辑尤其有用，导入资料库后顺序不会乱 |
| 发行年份 | 来自专辑发行时间 |
| 歌词 | 内嵌纯文本歌词；另可勾选生成同名 `.lrc`（含翻译） |
| 网易云歌曲 ID | 写入自定义标签，方便以后溯源 |

支持 MP3、FLAC、M4A、MP4、OGG、Opus。使用 `mutagen` 只修改标签区，**不重新编码，音质零损失**。

想自己验证，在项目目录执行：

```bash
python -c "from tags import inspect_tags; print(inspect_tags('歌曲文件.mp3'))"
```

## 10. 设置项速查

| 设置 | 作用 |
| --- | --- |
| 下载目录 | 默认 `music` 文件夹；`.` = 程序根目录 |
| 默认音质 | 下载用的音质，**默认「极高 320 kbps」，不需要会员**；各页面的音质下拉可临时改 |
| **播放音质** | 在线试听专用，标准 / 极高 / 无损 / Hi-Res，取不到自动降级；与下载互不影响 |
| **播放模式** | 顺序播放 / 单曲循环 / 随机播放（播放器右下角按钮也能切） |
| 并发数 | 1–8，网络好可以调高，不稳定就调低 |
| 封面尺寸 | 300 / 500 / 800 / 1200 px |
| **批量合并到文件夹** | 每次批量下载按任务标题建一个子目录；下载前仍可单独勾选覆盖 |
| 文件命名 | 简单模式（勾选式，含序号连接符与位数）/ 模板模式，均有实时预览 |
| 内嵌歌词 / 额外 .lrc | 歌词写入方式 |
| 跳过已存在 | 避免重复下载 |
| 按专辑分目录 | 默认关闭（全部平铺在下载目录） |
| 下载凭证 | 网易云 Cookie，**下载与在线播放共用** |
| 推荐偏好 / 动态权重 | 曲风 / 语言在首次使用时选择；之后的播放 / 收藏会在 `settings.json` 里累积 `pref_weights`，只影响推荐 |
| 界面主题 | 浅色 / 深色，自动记忆 |

设置保存在根目录 `settings.json`，Cookie 在 `cookie.txt`，收藏与歌单在 `cloudbox.db`。

**改一项存一项**：设置页的每个控件都是改完立刻写盘（先写 `settings.json.tmp` 再原子替换），不存在「忘记保存」或关窗丢失；下次打开自动读回。想恢复出厂设置就关掉软件、删掉 `settings.json` 再启动。

## 11. 常见问题

**下载提示「该音质需要黑胶会员」/「无版权 / 歌曲下架」**
换成标准或极高音质，或配置有效会员 Cookie。批量任务会逐首标原因，其它歌不受影响。

**提示 CDN 403 / 网络错误**
内置三次自动重试（换请求头 → 重新取直链 → https）。仍失败时重新点一次下载即可，已完成的文件会自动跳过。

**窗口没弹出来 / 一片空白**
确认 Edge WebView2 运行时可用；程序会自动降级为 Edge 独立窗口或默认浏览器。控制台会打印实际使用的窗口模式和本地地址。

**播放器里看不到封面或歌词**
确认「内嵌歌词」已开启；个别老旧播放器请换用支持 ID3v2.3 / Vorbis Comment 的播放器（如 foobar2000、MusicBee、VLC）。在线播放本身不显示滚动歌词，歌词写在下载后的文件里。

**在线播放为什么不是无损？**
先确认 `cookie.txt` 里的登录态还有效（`设置 → 下载凭证` 会显示 Cookie 状态与账号）。有 Cookie 时播放会优先取会员直链；如果标签只显示「极高」或「标准」，说明该曲没有更高档位、会员等级不够（如 Hi-Res 需更高等级），或 Cookie 已过期，服务端已自动降级到能播的档位。切换 `设置 → 在线播放 → 播放音质` 后可在播放器标签上看到实际结果。

**在线播放能播会员专享歌曲吗？**
能。v3.4.1 起 `/api/stream` 会带 `cookie.txt` 的登录态解析直链（之前是写死的匿名请求，所以会员歌返回 404）。没有 Cookie 时仍可播放公开曲目，会员曲目会提示「配置会员 Cookie 后可播放」。

**推荐会不会读取我的 Cookie / 做个性化？**
读 Cookie：不会，推荐请求显式传空 Cookie。个性化：会，但只在本机 —— 推荐页的播放 / 收藏 / 下载会累积「曲风 / 语言 / 歌手」权重，存在 `settings.json`，不上传、不关联账号。在线播放和下载才会读取 `cookie.txt` 以解锁会员内容。

**为什么点「换一批」后歌完全变了？会重复吗？**
每次刷新会换一张公开榜单、榜单内向后滑动一段，同时把偏好检索的页码往后翻；页码在约 60 首的范围内轮换，翻到头会回到开头，因此偶尔看到重复歌曲是正常的。

**推荐越来越偏怎么办？**
点推荐页说明区的「重置动态权重」，或在偏好弹窗重新保存一次选择；也可以只打开 `settings.json` 把 `pref_weights` 改回 `{"genres":{},"languages":{},"artists":{}}`。

**收藏 / 歌单换电脑还在吗？**
在 `cloudbox.db` 里，复制该文件到新机器的程序根目录即可。

**Cookie 保存后状态没变**
点顶部状态胶囊进入设置，或重新打开窗口刷新状态；也可用「退出登录」后重新扫码。

**日志在哪**
根目录 `music_api.log`。启动脚本异常时也会在控制台打印错误原因。

## 12. 开发者备注

- 本地服务只监听 `127.0.0.1` 的随机空闲端口，不对外暴露。
- 所有页面资源内联，无 CDN 依赖；封面经 `/api/cover` 代理，避免防盗链。
- 推荐模块 `discover.py` 显式传空 cookies；`/api/recommend?refresh=1` 推进轮换序号（榜单轮换 + 检索 offset）；`/api/preferences/feedback` 记录点击权重，`/api/preferences/reset` 清零。
- `/api/stream` 支持 `Range` / `206 Partial Content`，并优先用 `cookie.txt` 登录态解析直链（`/api/stream/info` 可查实际档位与来源）。
- 账号模块 `accounts.py` 使用 SQLite（本机免登录），表：`users` / `favorites` / `favorite_artists` / `local_favorites` / `playlists` / `playlist_songs`。
- 旧 API（`/song` `/search` `/playlist` `/album` `/download` 等）全部保留，详见 `README.md`。
- 主要模块：`desktop.py`（窗口）、`server.py`（路由）、`discover.py`（公开推荐）、`accounts.py`（账号）、`downloader.py`（下载与批量）、`tags.py`（元数据）、`music_api.py`（网易云接口）、`config.py`（配置）。
- 改完 `templates/index.html` 后需重启服务（生产模式会缓存 Jinja 模板）。
