## ✨ 这版改了什么

原项目是一个需要 `pip install` → `python main.py` → 打开浏览器的 Flask 网页服务，下载走浏览器文件流，元数据写入依赖外部 `ffmpeg`（Windows 上通常没有）。本次改造：

| 项目 | 改造前 | 改造后 |
| --- | --- | --- |
| 形态 | 命令行启动的 Web 服务 | 原生桌面窗口（WebView2），双击即用 |
| 依赖 | 需手动装 10+ 包、需 ffmpeg | 启动脚本自动装依赖；元数据用纯 Python `mutagen`，**不需要 ffmpeg** |
| 落盘 | 浏览器另存为 / `downloads/` 子目录 | **自动保存到 music 文件夹，目录可改** |
| 元数据 | ffmpeg 写入，常失败 | 标题 / 歌手 / 专辑 / 专辑艺术家 / 音轨号 / 碟号 / 年份 / 歌词 / **封面** / 网易云 ID，MP3·FLAC·M4A·MP4·Ogg 全覆盖 |
| 批量 | 只能逐首点 | 整张专辑、整个歌单、搜索结果勾选，多线程并发 + 逐曲进度 + 取消 + 跳过已存在 |
| 登录 | 命令行二维码（接口不匹配） | 窗口内扫码登录 / 手动粘贴 Cookie，状态实时显示 |
| 界面 | Bootstrap CDN + jQuery（离线打不开） | 完全自包含的现代桌面 UI，浅色 / 深色主题，零外部 CDN |
| 稳定性 | eapi 拼接 JSON 会解析崩溃、直链偶发 403 | JSON 容错解析、直链失败自动重试并重新取链、歌单/专辑批量取详情与直链 |
| 主页 | 三个功能说明卡 + 快速入口 | **歌曲推荐**：公开榜单 / 新歌 / 新碟，可直接播放、收藏、下载；「换一批」轮换榜单窗口与检索页，**按本机点击权重动态重排** |
| 播放 | 无 | 底部常驻流媒体播放器，会员 Cookie 优先解析直链 + Range 拖动进度 |
| 账号 | 只有网易云 Cookie | **本机档案**（本地 SQLite，免注册免登录）：在线收藏 / 收藏歌手 / 本地收藏 / 自建歌单；Cookie 用于下载与在线播放 |

## 🔧 v3.5.0 动态推荐

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 点「换一批」，推荐列表完全不变 | 原来只是绕过缓存后重跑同样的请求：新歌接口固定、热歌榜固定取前 20 首、偏好关键词也固定，结果自然一致。现在每次刷新都会推进 `nonce`：<br>① 热歌在「热歌 / 飙升 / 原创 / 新歌」四张公开榜单间轮换，并在榜内滑动窗口取 12 首；<br>② 偏好检索带上 `offset`（每次 +8，60 首内轮换），关键词顺序也会按 `nonce` 轮转；<br>③ 前端「换一批」加并发保护，请求期间不会重复触发 |
| 2 | 想按自己的点击偏好动态推荐 | 新增本机权重模型：推荐页的**播放 / 收藏 / 下载**会上报歌曲标签，服务端按 `播放 +0.3 / 下载 +0.5 / 收藏 +1.0`（歌手 ×0.8）累加，越接近上限增量越小；20 秒内同曲同动作只记一次。权重写进 `settings.json` 的 `pref_weights`，并立即清空推荐缓存 |
| 3 | 权重要真的影响结果 | 生成推荐时：曲风 / 语言按权重排序，权重 ≥1.6 多检索一页、≥3.2 再多一页；高权重歌手直接作为搜索关键词补充新歌；顶栏与说明区显示 `爵士 ×1.3 · 欧美 ×1.2` 等实际权重 |
| 4 | 换了偏好 / 想重来 | 重新保存偏好会把所选曲风 / 语言重置为 1.0 并清空歌手权重；推荐页说明区提供「重置动态权重」，接口为 `POST /api/preferences/reset` |

隐私边界不变：权重只存在本机，推荐请求仍显式 `cookies={}`，不上传、不关联账号。

## 🔧 v3.4.1 修复：会员歌曲无法在线播放

**现象**：填了会员 Cookie 后，下载会员歌曲 / 会员音质都正常，但点 ▶ 在线播放会员曲目时提示「无法播放」。

**原因**：`/api/stream` 的直链解析被写死成匿名请求（`get_song_url(..., {})`）。会员曲目匿名拿到的 `data[0].url` 是空的，服务端于是返回 404，`<audio>` 触发 error；下载走的是带 Cookie 的 `service.url_map()`，所以下载不受影响。

**处理**：

| 项 | 改动 |
| --- | --- |
| 播放直链 | 新增 `_resolve_stream()`：优先带 `cookie.txt` 登录态按 播放音质 → 逐级降级 解析，失败后再退回匿名公开音质 |
| 音质档位 | 播放音质新增 **Hi-Res**；`lossless / hires` 需会员 Cookie，取不到自动降到 `exhigh / standard` |
| 播放器标识 | 歌名下方新增小标签：`会员 · 无损`、`会员 · Hi-Res` 或 `极高`（匿名），一眼看出当前用的是登录态还是公开音质 |
| 失败提示 | 新增 `GET /api/stream/info`，播放失败时给出准确原因（Cookie 过期 / 会员专享 / 版权下架），不再只说「无法播放」 |
| 音频 MIME | 会员无损上游常把 FLAC 标成 `audio/mpeg`，现按真实后缀返回 `audio/flac`，避免部分环境解码失败 |
| 缓存 | 音频流响应改为 `private`，会员直链不进入共享缓存 |

## 🚀 运行

### 方式一：直接双击 exe（最省事）

根目录已附带 **`CloudBox.exe`**（约 21 MB，单文件，已实测可打开原生窗口）。双击即可，**不需要 Python、不需要装依赖**。

exe 所在的文件夹就是「根目录」：`cookie.txt`、`settings.json`、`cloudbox.db`（收藏与歌单）与下载的歌曲都在这里。换电脑时把 exe 和 `cloudbox.db` 一起复制走即可；`cookie.txt` 建议在新机器上重新登录生成，不要通过聊天工具或网盘传输。

**给别人的分发包**：执行 `python pack_dist.py` 生成 `release-package/`，里面只有 `CloudBox.exe` + `cookie.example.txt`（占位，**不含真实 Cookie**），**不含本机的 settings.json、cloudbox.db 和 music 目录**；对方首次双击会自动生成一套默认设置，`music` 文件夹也建在 exe 同级。默认下载音质为「极高（320 kbps）」，不需要会员。

> **注意**：`settings.json` 是实时写入的（改一项存一次，先写临时文件再替换），关掉再开不会丢。

> Windows 10/11 自带的 Edge WebView2 运行时用于显示窗口；若不可用，会自动降级为 Edge/Chrome 独立窗口或默认浏览器。

### 方式二：一键启动脚本（改代码 / 更新依赖时用）

双击 **`启动桌面版.bat`**。第一次运行会自动创建 `.venv` 并安装依赖（约 1 分钟，需要联网），之后秒开。需要 Python 3.10+（安装时勾选 "Add Python to PATH"）。

### 方式三：重新打包 exe（可选）

双击 **`打包EXE.bat`**：产物在 `dist/CloudBox.exe`，脚本会顺手刷新 `release-package/`（exe + `cookie.example.txt`）。分发时把 `release-package` 文件夹整体打包发出即可，**不要附带 `cookie.txt`**。

### 方式四：手动 / 兼容旧用法

```bash
pip install -r requirements.txt
python desktop.py                 # 桌面窗口
python desktop.py --server        # 仅启动本地服务（默认 5000 端口，兼容旧文档）
python main.py                    # 等价于 python desktop.py
```

## 🎵 使用

1. **打开就能用**：软件没有注册 / 登录流程，第一次启动自动在本机建 `cloudbox.db`，收藏、歌手与自建歌单直接写进去，与网易云账号无关。
2. **逛推荐**：主页展示公开榜单歌曲、热门榜单与新碟，点 ▶ 在线播放、♥ 收藏、⬇ 下载；点榜单 / 专辑卡片可展开并整批下载。点「换一批」会换一版内容；在本页播放 / 收藏 / 下载会累积「曲风 / 语言 / 歌手」权重，下一次刷新按新口味排序（权重只存本机）。
3. **搜索与下载**：主页搜索框或搜索页可切「歌曲 / 专辑 / 歌单」；单曲解析页输入 ID 或链接；歌单 / 专辑页可整批下载，搜索结果可勾选批量。批量栏可勾选「合并到一个文件夹」。
4. **配置 Cookie**（可选，解锁会员歌曲与高音质）：设置 → 下载凭证 → 扫码或粘贴。**下载与在线播放共用**，不参与推荐与软件账号。
5. **看进度**：下载队列页有总进度、成功 / 跳过 / 失败统计、每首的元数据写入结果与「定位文件」。
6. **找文件**：所有歌曲默认输出到程序根目录下的 **`music`** 文件夹；设置里可改目录（填 `.` 输出到根目录），或开启「按专辑分目录」。

支持的输入格式：`185668`、`https://music.163.com/song?id=...`、`https://music.163.com/#/playlist?id=...`、`163cn.tv` 短链、以及夹杂链接的分享文案。

## 🎧 推荐、在线播放与本机档案

这几块是刻意互相隔离的，重点是 **Cookie 只服务「听 / 存」，不参与推荐**：

| 能力 | 数据来源 | 是否用 Cookie | 是否需要登录 |
| --- | --- | --- | --- |
| 歌曲推荐 | 公开榜单 / 新歌 / 新碟；若填过偏好，再按「曲风 + 语言 + 歌手」公开检索。点击权重只写本机 `settings.json`，`discover.py` 仍显式传空 cookies | ❌ 不读取 `cookie.txt`，不关联任何账号 | 不需要 |
| 在线播放 | `/api/stream` 代理直链，支持 `Range` / 206 拖动进度；**优先带 Cookie 解析**（会员歌曲 / 无损可用），失败退回匿名公开音质 | ✅ 读取（没有也能播公开曲目） | 不需要 |
| 收藏 / 收藏歌手 / 本地收藏 / 自建歌单 | 本机 `cloudbox.db`（SQLite） | ❌ 不读取 | **没有登录**，打开即用 |
| **下载歌曲** | 会员音质直链 + `mutagen` 写标签 | ✅ 读取（解锁会员音质） | 不需要 |

- **本机档案**：v3.3 起去掉了注册 / 登录，第一次启动自动在根目录建 `cloudbox.db`，收藏与歌单直接写入本机；删除该文件即清空，不上传、不联网、与网易云账号无关。
- **三类收藏分开存**：在线歌曲（`favorites`）、收藏歌手（`favorite_artists`）、本地文件（按路径记录），「我的音乐」页分标签展示，互不混淆。
- **首次使用推荐**会问一次喜欢的曲风与语言，可多选也可「先跳过」；偏好只存在 `settings.json`，随时可改。
- 底部播放器常驻，支持顺序 / 单曲循环 / 随机；正在播放的歌曲行按钮会变成 ⏸，再点即暂停。有 Cookie 时播放器会标注「会员 · 无损」之类的标签，说明当前用的是会员登录态；没有 Cookie 则退到匿名公开音质。
- 鼠标 **侧键（前进 / 后退）**可在软件内翻页。
- 下载目录规则：整张专辑 / 歌单落到以内容名命名的子文件夹，单曲直接放 `music` 根目录；勾选「合并到一个文件夹」则一律建子目录。

## 🏷️ 元数据说明

下载完成后自动写入，不重编码、音质零损失：

| 格式 | 标签体系 | 封面 |
| --- | --- | --- |
| MP3 | ID3v2.3（TIT2 / TPE1 / TPE2 / TALB / TRCK / TPOS / TDRC / USLT / APIC / TXXX） | APIC 前置封面 |
| FLAC | Vorbis Comment | METADATA_BLOCK_PICTURE |
| M4A / MP4 | iTunes atoms（©nam / ©ART / ©alb / aART / trkn / ©day / ©lyr / covr） | covr |
| OGG / Opus | Vorbis Comment | METADATA_BLOCK_PICTURE (base64) |

设置里可开关「内嵌歌词」「额外保存 .lrc」「跳过已存在」「按专辑分目录」「批量合并到文件夹」，并可调整封面分辨率。

**文件命名**提供两种模式（带实时预览）：

- **简单模式（默认）**：勾选即可——包含歌手 / 专辑 / **专辑内顺序** / 歌曲 ID / 音质，可选「歌名在前或歌手在前」「多位歌手全部保留或仅第一位」「连接符」。勾选「包含专辑内顺序」后还能细调 **序号与后面内容的连接符**（`. ` / ` - ` / `_` / 空格 / 顿号 / `[01] ` 方括号）和 **序号位数**（1 / 2 / 3 位），例如 `001 - 起风了.flac`。下方实时预览三首示例
- **模板模式**：`{name}` `{artist}` `{album}` `{track}` `{track:02d}` `{year}` `{id}` `{quality}` 自由组合，示例：`{track:02d}. {name} - {artist} ({year})`

## ⚙️ 配置

所有配置保存在根目录 `settings.json`，Cookie 沿用 `cookie.txt`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `output_dir` | `music` | 下载目录；相对路径基于程序根目录，`.` = 根目录 |
| `quality` | `exhigh` | 默认「极高 320 kbps」，不需要会员也能完整下载；要会员音质再往上选 lossless / hires 等 |
| `concurrency` | `3` | 批量并发数 1–8 |
| `naming_mode` | `simple` | `simple` 勾选式命名 / `template` 模板命名 |
| `naming_include_artist` 等 | 见 `config.py` | 简单模式的勾选项、顺序、连接符 |
| `naming_include_track` | `false` | 是否包含专辑内顺序（序号前缀） |
| `naming_track_separator` | `. ` | 序号与后面内容的连接符，6 种可选 |
| `naming_track_digits` | `2` | 序号位数：1 / 2 / 3（不足补零） |
| `batch_in_folder` | `false` | 批量下载时按任务标题建一个文件夹；下载前可单独勾选覆盖 |
| `play_quality` | `exhigh` | 在线播放音质：standard / exhigh / lossless / hires，与下载音质分离；无损及以上需 Cookie |
| `play_mode` | `order` | 播放模式：order 顺序 / one 单曲循环 / shuffle 随机 |
| `pref_genres` / `pref_languages` | `[]` | 首次使用选择的曲风 / 语言偏好，用于公开检索推荐 |
| `pref_weights` | 空 | 推荐页点击累积的动态权重：`{"genres": {...}, "languages": {...}, "artists": {...}}`，取值 0.2–6.0，只存本机 |
| `pref_done` | `false` | 是否已完成首次推荐偏好引导（跳过也会置为 true） |
| `filename_template` | `{artist} - {name}` | 模板模式的文件名模板 |
| `embed_lyrics` / `save_lrc` | `true` / `false` | 歌词写入方式 |
| `skip_existing` / `group_by_album` | `true` / `false` | 跳过已存在 / 按专辑建子目录 |
| `cover_size` | `800` | 封面分辨率 |
| `theme` | `light` | light / dark |

> 高音质需要**黑胶会员 Cookie**，SVIP 音质（sky / jymaster）需要 SVIP。标准与极高音质通常无需登录。个别歌曲因版权下架会返回 404，界面会标注具体原因。

## 🔌 API

本地服务仅监听 `127.0.0.1` 的随机空闲端口。桌面版新接口：

```
GET  /api/state            应用状态 / 设置 / 依赖 / Cookie
POST /api/settings         保存设置
GET  /api/search           搜索（type=1 歌曲 / 10 专辑 / 1000 歌单）
GET  /api/song             单曲解析（详情 + 直链 + 歌词）
GET  /api/resolve          解析歌单 / 专辑，返回完整曲目
POST /api/download         单曲下载到 music 文件夹
POST /api/naming/preview   按当前设置生成文件名示例
GET  /api/recommend        推荐列表（refresh=1 换一批；按本机权重排序）
GET  /api/recommend/chart  展开某个公开榜单
GET  /api/preferences      当前动态权重摘要
```

## ❓ 常见问题

**Q：首次启动很慢 / 装依赖失败？**
首次需要联网装依赖（走阿里云镜像，失败自动回退官方源）。之后不再需要网络安装。

**Q：下载提示「当前音质不可用 / 无版权」？**
换标准或极高音质，或在设置里配置有效会员 Cookie。批量任务会逐首标注原因，不影响其它歌曲。

**Q：提示 CDN 403？**
已内置三次重试（换请求头 → 重新取直链 → https），仍失败通常是链接时效或网络代理问题，重试该任务即可（已下载的会自动跳过）。

**Q：播放器看不到封面 / 歌词？**
确认设置里「内嵌歌词」已开启；部分老播放器只认 ID3v2.3，MP3 已按 v2.3 写入。可用 `python -c "from tags import inspect_tags; print(inspect_tags('歌曲.mp3'))"` 验证。

**Q：想改输出位置？**
设置 → 输出位置，填完整路径；留空或填 `music` 即默认 music 文件夹，`.` 为程序根目录。

**Q：推荐 / 在线播放会用到我的网易云 Cookie 吗？**
推荐不会：`discover.py` 显式传入空 cookies，只读公开榜单与新歌；推荐里的「口味权重」只存本机 `settings.json`，不上传。在线播放会：`/api/stream` 优先用 `cookie.txt` 的登录态解析直链，会员歌曲、无损 / Hi-Res 才拿得到；Cookie 失效或没配置时自动退回匿名公开音质。

**Q：软件账号的数据在哪？换电脑怎么带走？**
在本机 `cloudbox.db`，没有密码也没有登录态。把 `cloudbox.db` 和 `cookie.txt` 复制到新机器的程序根目录即可；不复制就是全新的空收藏库。

**Q：在线播放能播会员歌曲吗？为什么音质会降级？**
可以，前提是 `cookie.txt` 是有效的会员登录态。播放器会在歌名下方标注「会员 · 无损 / Hi-Res」或只写「极高」，说明实际拿到的档位。以下情况会自动降级到能播的档位：该曲没有更高音质母带、会员等级不够（如 Hi-Res 需更高等级）、Cookie 过期。想确认某首歌的实际情况，可看 `/api/stream/info?id=歌曲ID&level=lossless` 返回的 `level` 与 `source`。

**Q：「换一批」的推荐是怎么变的？**
每次刷新服务端会推进一个轮换序号：热门歌曲在四张公开榜单之间换、并在榜内向后滑动取一段；按偏好检索时页码也向后翻（约 60 首内轮换），关键词顺序同时轮转。因此连续点「换一批」会看到不同的歌；翻到末尾会回到开头，偶尔重复属于正常现象。

**Q：推荐为什么会越来越像我的口味？怎么清掉？**
推荐页的播放 / 收藏 / 下载会累加「曲风 / 语言 / 歌手」权重（收藏权重最高），下一次刷新按权重排序与扩展检索。觉得跑偏了点推荐页说明区的「重置动态权重」，或到设置里重新保存一次偏好即可回到初始状态。

**Q：批量下载怎么让整张专辑进同一个文件夹？**
设置 → 「批量合并到文件夹」打开后，每个批量任务会按标题建一个子目录；下载前批量栏里也有同名的单次勾选，可临时覆盖。序号命名在 设置 → 文件命名 → 简单模式 → 「包含专辑内顺序」里细调连接符与位数。
